# Unified TWRP Device Tree for the Xiaomi Redmi Note 10 Pro/Pro Max (sweet/sweetin)

The Xiaomi Redmi Note 10 Pro/Pro Max (codename _"sweet/sweetin"_) is a mid-range smartphone series introduced by Xiaomi in March 2021. This lineup includes both global and Indian variants, which share a largely identical hardware platform but differ in regional branding, camera configurations, and internal codenames.
